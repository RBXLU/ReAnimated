# ReAnimated: Bounce — пример расширения

Маленький мод, написанный только на публичном API ReAnimated: ни миксинов, ни доступа
к внутренностям. Делает ровно две вещи:

- **добавляет свою анимацию появления «Jump»** — экран падает сверху, ударяется о своё
  место и пару раз подпрыгивает, затухая, слегка сплющиваясь на ударах;
- **добавляет кнопку в настройки ReAnimated** (секция «Расширения»), которой анимацию
  можно выключить: надпись показывает состояние и переключается по нажатию.

Выключение сделано честно — анимация снимается с регистрации
(`ReAnimatedApi.unregisterPreset`), пропадает из списка пресетов, и ReAnimated сам
возвращает экраны к обычному пресету. Выбор в конфиге при этом сохраняется: включите
обратно — вернётся и анимация.

## Сборка

Пример собирается против jar'а самого ReAnimated, поэтому сначала соберите основной мод:

```bash
cd ../../1.21.11 && ./gradlew build
cd ../examples/bounce && ./gradlew build
```

Готовый файл — `build/libs/reanimated-bounce-1.0.0.jar`.

## Установка

В `mods/` кладутся оба мода: **ReAnimated** для 1.21.11 и **reanimated-bounce**
(плюс Fabric API). Дальше:

1. Настройки → Настройки графики → «Настройки ReAnimated»
2. Секция **«Расширения»**: строка **«Анимация расширения»** — выберите в ней *Jump*
3. Там же кнопка **«Bounce: ON / OFF»** — выключает и включает анимацию

## Что в коде смотреть

| Файл | Про что |
|---|---|
| `BouncePreset.java` | Вся анимация: по прогрессу 0..1 возвращается положение экрана (сдвиг и масштаб) |
| `BounceClient.java` | Регистрация анимации и кнопки в настройках |
| `BounceConfig.java` | Своё состояние в своём файле — в конфиг ReAnimated расширение не лезет |

## Прогон API без игры

Пакет `com.pycodder.reanimated.api` не тянет за собой ни классов Minecraft, ни классов
загрузчика, поэтому его можно взять прямо из jar'а мода и погонять обычной джавой:

```bash
SLF4J=$(find ~/.gradle/caches/modules-2 -name 'slf4j-api-*.jar' | grep -v sources | head -1)
CP="../../1.21.11/build/libs/reanimated-1.21.11+1.7.jar:$SLF4J"
javac -cp "$CP" -d apitest apitest/ApiSmokeTest.java
java -Dstdout.encoding=UTF-8 -cp "$CP:apitest" ApiSmokeTest
```

Проверяются регистрация и снятие анимаций, форма кривой прыжка, правила «анимировать ли
экран», события, кнопки в настройках, снимок состояния и — отдельно — что падающее
расширение не роняет игру.
